# 인팩트컴퍼니 홈페이지 — 디자인 작업용 사본

운영 중인 홈페이지(infactcompany.com)의 **화면만** 그대로 옮긴 폴더입니다. 모션·애니메이션은 전부 들어 있고, 관리자 페이지·데이터베이스·검색 노출 설정·방문 분석은 빠져 있습니다.

**이 폴더에서 무엇을 바꿔도 운영 사이트에는 영향이 없습니다.** 마음 편히 수정하셔도 됩니다.

## 시작하기

1. VS Code 에서 이 폴더(`infactcompany_design`)를 엽니다. 상위 폴더가 아니라 꼭 이 폴더를 여세요.
2. 이 컴퓨터에서 처음 여는 것이라면 터미널에서 `npm install` 을 한 번 실행합니다. (Node.js 20.9 이상이 설치되어 있어야 합니다 — https://nodejs.org 의 LTS 버전)
3. 터미널에서 `npm run dev` 를 실행합니다.
4. 브라우저에서 http://localhost:3000 을 엽니다. 파일을 저장하면 화면이 바로 바뀝니다.

## 볼 수 있는 페이지

- `/` 메인
- `/services` 서비스
- `/blog` 블로그 목록과 글 상세 (샘플 글 4개)
- `/contact` 문의 — 폼은 화면만 동작하고 실제로 접수되지는 않습니다
- `/privacy` 개인정보 처리방침
- `/company-profile` 회사소개서

## 알아둘 점

- 문구와 이미지는 2026-10-12 기준 운영 사이트 내용을 복사해 둔 것입니다. 이후 운영 사이트에서 바뀐 내용은 자동으로 따라오지 않습니다.
- 완성한 디자인을 운영 사이트에 반영하는 일은 개발 담당자가 따로 옮깁니다. 이 폴더를 그대로 배포하지 마세요.
